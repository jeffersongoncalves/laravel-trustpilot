# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-09-08

First release.

- `businessUnits()` — search, get, profile, categories, web links
- `reviews()` — public list/get/latest, private list, reply, delete reply
- `invitations()` — email invitations, invitation links, templates
- `tags()` — get, add, remove review tags
- API key auth for public endpoints, cached client-credentials bearer token for private ones
- Configurable default business unit
- `TrustpilotException` on any non-2xx response
